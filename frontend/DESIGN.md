# vrstudio 前端设计计划（Phase 0）

本文件只记录新前端的视觉方向与令牌，不替代 `docs/plan/frontend-refactor-plan.md` 的实施计划。

## 1. 页面要做什么

这是一个局域网内的视频生产工具，不是展示页。页面的首要任务是让使用者在一屏内回答三件事：当前在哪个 case、这一步要做什么、提交前还差什么。视觉方向因此选择冷静的工具型界面，而不是暖色纸张或营销页风格。

## 2. 颜色

颜色采用中性冷灰表面加一个蓝色主色，成功、警告、危险、信息各有独立语义色。这套取值避开“暖奶油底加衬线标题加陶土色”这类常见默认。

- 页面底色：`#f4f6f9`
- 卡片表面：`#ffffff`
- 次级表面：`#f8fafc`
- 边框：`#e2e8f0`，强调边框 `#cbd5e1`
- 主文字：`#1f2937`
- 次要文字：`#64748b`
- 弱文字：`#94a3b8`
- 主色：`#2563eb`，浅底 `#eff6ff`
- 成功：`#16a34a`，浅底 `#f0fdf4`
- 警告：`#d97706`，浅底 `#fffbeb`
- 危险：`#dc2626`，浅底 `#fef2f2`
- 信息：`#0891b2`，浅底 `#ecfeff`

## 3. 字体

- 正文与标题使用系统中文字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。
- 帧号、路径、日志、任务 ID 使用等宽字体：`"JetBrains Mono", Consolas, "Courier New", monospace`。
- 字号六级：12、13、14、16、20、24、32 像素；正文 14 像素，行高 1.6。
- 标题不做装饰性衬线，不把单个词换成斜体或另一种颜色。

## 4. 布局

- 左侧导航 220 像素，可折叠到 64 像素；顶部栏 56 像素；主内容区左右留 32 像素。
- case 列表用表格，生成页用两栏，选区页用左画面右参数，对比页用整幅画布加底部控制条。
- 生成页的提交控件固定在内容区底部，不随页面滚动消失。
- 最小设计宽度 1280 像素；1024 到 1280 像素之间折叠侧栏；低于 1024 像素提示使用更宽窗口。
- 圆角统一 4、6、8 像素；阴影只用于抽屉、对话框与下拉。

## 5. 信息层级

- 每个页面只有一个主行动：case 列表是“新建 case”，生成页是“提交生成”，选区页是“保存选区”。
- 说明文字离开正文：常驻说明只保留一句话，详细说明放进悬停提示、抽屉或帮助块。
- 状态必须可见：加载、空、错误、禁用原因、保存中、已保存、排队中、运行中、失败。
- 长内容默认折叠：提示词、日志、文件列表都先给摘要，展开后再看全文。

## 6. 动效与可访问性

- 动效只用于状态变化，时长 150 到 200 毫秒；尊重 `prefers-reduced-motion`。
- 正文对比度至少 4.5 比 1；焦点样式可见；控件可键盘到达。
- 不做每张卡片淡入，不做滚动触发动画。

## 7. Phase 0 原型

Phase 0 先做两个原型页面：case 列表与生成页。两个页面都使用真实长度的中文内容与真实路径，不使用占位文本；1440 与 1920 两个宽度各截一次图，检查横向溢出、长文件名换行与控件挤压。
